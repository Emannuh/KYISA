Setup Instructions

GavaConnect KRA Setup
  1. Register at sandbox.gavaconnect.co.ke
  2. Create an App in your dashboard
  3. Subscribe to "Fetch Taxpayer Obligations" and "PIN Checker by ID"
  4. Copy your Client ID and Client Secret
  5. Add to Railway: GAVACONNECT_CLIENT_ID, GAVACONNECT_CLIENT_SECRET
  6. Set GAVACONNECT_ENVIRONMENT=sandbox for testing, production for live
  7. Test PIN: P051234567A
Prembly IPRS Setup
  1. Log in at app.prembly.com
  2. Go to API Keys and copy your live key
  3. Add to Railway: PREMBLY_API_KEY
  4. Set PREMBLY_ENVIRONMENT=production
  5. Test ID (sandbox): 10101010
  6. Photo is returned only via the SDK flow (not the API endpoint)
